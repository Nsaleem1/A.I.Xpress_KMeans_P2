# A.I.Xpress_KMeans_P2

##### In Fall of 2025, we were approached by Mr. Keogh, who asked for assistance on a business problem. As he explained, he owns an almond farm that contains Navel Orangeworms (NOW) whose larva infects the almonds. A company tells Mr. Keogh which tree locations he should apply a pheromone paste to minimize the NOW. Mr. Keogh has a total of 4 drones, but he must supervise the drones while they apply the paste which move at about 100 meters per minute. Mr. Keogh would like to minimize this time by being able to see the cost of using 1-4 drones. Mr. Keogh wants to know where the landing pad(s) should be, what locations each drone visits, and the total meters each drone travels separately and combined. Mr. Keogh selects the amount of drones he wants to use himself, he simply wants us to present the information. Based on this problem, we concluded this requires a K-means cluster algorithm to optimally group the locations for more than one drone.
